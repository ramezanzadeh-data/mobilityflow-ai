# ---------------- AI (local LLM via Ollama) ----------------
# No `ollama` client package. The project talks to Ollama over its
# documented HTTP API from core/ai/ollama_client.py using `requests`
# (listed above), for two reasons found in production:
#
#  * the client package builds a module-level HTTP client at import time
#    with the timeout disabled (Timeout(timeout=None)), so a backend that
#    accepted the connection and then went quiet blocked the caller
#    forever - a permanent spinner in Streamlit, a held slot in Celery;
#  * building that client at import time made the whole test suite
#    depend on it, and it failed collection outright behind a proxy.
#
# tests/test_ai_client_boundary.py fails if the import is reintroduced.
#
# pydantic: structured payload schemas for the AI Response Formatter
# (core/ai/schemas.py, core/ai/response_formatter.py)
